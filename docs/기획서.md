## 1. 서비스 개요

### 앱 이름
**MFlow** (Money Flow)

### 컨셉
주식 시세, 뉴스, AI 분석을 한 곳에서 볼 수 있는 개인 투자자용 주식 정보 앱

### 타겟 사용자
- 주식 투자에 관심 있는 개인 투자자
- 실시간 시황과 뉴스를 빠르게 파악하고 싶은 사람
- 종목 선택에 도움이 필요한 초보~중급 투자자

### 플랫폼
- iOS / Android (Flutter)
- Web (GitHub Pages 배포)
- 향후: Apple Watch 연동 예정

## 2. 핵심 기능 (현재 구현 완료)

### 2-1. 대시보드
- KOSPI / KOSDAQ 지수 실시간 표시 (현재 mock)
- 관심 종목 목록 (가격, 등락률, 미니 차트)
- 종목 탭 → 상세 화면으로 이동

### 2-2. 종목 검색
- 종목명으로 검색
- 검색 결과에서 종목 상세 화면 이동

### 2-3. 실시간 급등주
- 급등 TOP 5 (등락률 기준)
- 거래량 상위 종목

### 2-4. AI 추천
- 단기 추천 종목 (수시간~1일)
- 다음날 추천 종목
- 종목별 신뢰도 점수, 추천 이유, 목표가 표시
- (현재 mock 데이터, 향후 실제 AI 연동 예정)

### 2-5. 오늘의 뉴스
- 6개 언론사 RSS 피드 (매일경제, 서울경제, 한국경제, 이데일리, 머니투데이, 연합뉴스)
- 관련 종목이 있는 뉴스만 필터링 표시
- 뉴스 클릭 → 요약 + 뉴스 분석 + 관련 종목 예상 + 원문 보기
- 섹터별 분석: 방산, 반도체, 엔터, 전기차, AI, 금융, 원전, 해운 등
- 관련 종목 탭 → 종목 상세 화면 이동

### 2-6. 종목 상세
- 현재가, 등락률
- 기간별 차트 (1일/1주/1개월/3개월/1년)
- 거래 정보 (거래량, 거래대금, 전일종가)
- 관련 뉴스 자동 표시
