## 3. 데이터 흐름

### 뉴스 수집 흐름
```
RSS 피드 (6개 언론사)
    ↓
rss2json.com API (CORS 우회)
    ↓
NaverNewsService.fetchStockNews()
    ↓
NewsAnalysisService.analyze() 로 필터링
    ↓
관련 종목 예측이 있는 뉴스만 표시
```

### 종목 데이터 흐름 (현재)
```
mock_data.dart (정적 데이터)
    ↓
Dashboard / HotStocks / AIRecommend 화면
    ↓
ChartScreen (차트 + 거래정보)
```

### 종목 데이터 흐름 (향후 KIS API 연동 후)
```
KIS API (실시간 시세)
    ↓
StockService (신규 작성 예정)
    ↓
Dashboard / HotStocks / AIRecommend 화면
    ↓
ChartScreen (실시간 차트)
```

## 4. 뉴스 분석 로직

### 분석 우선순위
1. **섹터 룰 매칭** (높은 신뢰도)
   - 트리거 키워드 감지 → 관련 섹터 종목 + 방향 결정
   - 예: "전쟁", "미사일" → 방산주 상승 예상

2. **회사명 직접 매칭** (중간 신뢰도)
   - 뉴스 텍스트에서 회사명 감지
   - 일반 긍정/부정 키워드로 방향 결정

### 지원 섹터
| 섹터 | 트리거 키워드 | 관련 종목 |
|------|-------------|---------|
| 방산 | 전쟁, 미사일, 드론, 방위 | 한화에어로, 현대로템, LIG넥스원, KAI |
| 반도체 | HBM, D램, 파운드리, 반도체 | 삼성전자, SK하이닉스 |

| AI | ChatGPT, LLM, 인공지능 | 삼성전자, SK하이닉스, 네이버 |

## 5. 향후 API 연동 설계

### 5-1. KIS (한국투자증권) API
```
KisService (신규)
├── getStockPrice(symbol) → 현재가, 등락률
├── getChartData(symbol, period) → OHLCV 데이터
├── getMarketIndex() → KOSPI/KOSDAQ 지수
├── placeOrder(symbol, qty, price, side) → 매수/매도
└── getPortfolio() → 보유 종목
```

### 5-2. Claude API (뉴스 요약)
```
ClaudeService (신규)
└── summarizeNews(title, content) → 3줄 요약 + 관련종목 예측
```

### 5-3. 환경 변수 관리 (보안)
```
.env 파일 (gitignore에 추가)
├── KIS_APP_KEY=...
├── KIS_APP_SECRET=...
└── ANTHROPIC_API_KEY=...
```
- API 키는 절대 코드에 직접 넣지 않음
- Vercel 환경변수 또는 서버사이드에서 관리
